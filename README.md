# Talkie hero

Static Talkie hero page deployed as a Cloudflare Worker with static assets.

## Files

- `public/index.html` — page markup
- `public/assets/` — CSS, JavaScript, fonts, and background image
- `wrangler.jsonc` — Cloudflare deployment configuration

## Deploy

From this folder, run `npx wrangler deploy` using a Cloudflare account with access to the project.
